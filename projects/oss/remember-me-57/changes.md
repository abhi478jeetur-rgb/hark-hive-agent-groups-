| Key | Old | New | Why |
|---|---|---|---|
| `Due {when}` | नियत: {when} | समय: {when} | 'नियत' is formal; everyday wording |
| `Dismiss` | हटाएँ | ख़ारिज करें | Was same as Delete ('हटाएँ'); dismissing must not read like deleting |
| `Gray` | धूसर | ग्रे | 'धूसर' is rare; 'ग्रे' is everyday |
| `Forest` | वन | जंगल | More natural colour-theme name than 'वन' |
| `Coming up: {title}` | जल्द: {title} | जल्द ही: {title} | 'जल्द:' alone reads cut off |
| `Preview alert` | अलर्ट आज़माएँ | अलर्ट का पूर्वावलोकन | Said 'try alert'; now matches other preview strings |
| `Preview the alert` | अलर्ट देखें | अलर्ट का पूर्वावलोकन देखें | Consistent preview term |
| `Export backup` | बैकअप निर्यात करें | बैकअप एक्सपोर्ट करें | Common tech word instead of 'निर्यात' |

Nothing else is sent.` | Remember Me GitHub पर नए संस्करण जाँच सकता है और फिर से शुरू करने पर उन्हें इंस्टॉल कर सकता है। और कुछ नहीं भेजा जाता। | Remember Me GitHub पर नए संस्करण जाँच सकता है और रीस्टार्ट करने पर उन्हें इंस्टॉल कर सकता है। और कुछ नहीं भेजा जाता। | Same restart term |
